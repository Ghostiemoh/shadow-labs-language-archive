# Shadow Labs: Nigerian Language Archive

A dictionary, picture encyclopedia and data platform for Nigerian languages, starting with Hausa, Yoruba and Igbo.

Start with `CLAUDE.md` for the project brief, `docs/plan.md` for the staged plan, `docs/guide.md` for the step-by-step order, `docs/research.md` for findings, and `docs/roadmap.md` for next steps.

The app is the Next.js project at the repo root (live at https://yarasude.vercel.app). How it fits together: `docs/app.md`.
